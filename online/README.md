# 飞行棋 · 局域网 4 人联机 MVP 骨架

一个**服务器权威（server-authoritative）+ Socket.IO** 的联机骨架，跑通"4 人加入房间 → 各自轮到自己时操作 → 所有人状态实时同步"这条链路。

> 这是**骨架**，不是完整游戏。它的目的是让你先跑通联机架构，之后再把飞行棋的完整规则（1 鬼 vs 3 人、破译、抓人……）搬进 `game.js`。

---

## 目录结构

```
fxq-online/
├── game.js              # ★ 共享游戏逻辑（服务器权威，唯一真相来源）
├── server.js            # 服务器：房间管理 + 回合校验 + 广播
├── test-clients.js      # 自动化验证脚本（模拟 4 个客户端）
├── public/
│   └── index.html       # 客户端页面（渲染 + 发指令）
├── package.json
└── README.md
```

**核心分工**：
- `game.js`：规则逻辑，**只有服务器调用**，负责改状态；
- `server.js`：收指令 → 调 `game.js` 校验并改状态 → 广播快照；
- `index.html`：只做两件事——**把点击变成"发指令"**、**把收到的状态渲染出来**。

---

## 一、先决条件

- 所有玩家在**同一个 WiFi / 局域网**；
- 主机电脑装 **Node.js**（18+，[官网下载](https://nodejs.org)）。

---

## 二、启动（在主机电脑上）

```bash
cd fxq-online
npm install        # 第一次才需要，装依赖
npm start          # 启动服务器
```

看到这个就成功了：
```
==============================================
 飞行棋联机服务器已启动
 本机访问：   http://localhost:3000
 他人访问：   http://<你的内网IP>:3000
==============================================
```

## 三、查内网 IP 并分享

另开一个命令行：
```bash
ipconfig
```
找 **IPv4 地址**，形如 `192.168.1.23`。

然后：
- **主机自己**访问 `http://localhost:3000`
- **其他人**访问 `http://192.168.1.23:3000`（换成你查到的 IP）

各自输入名字、**填同一个房间号** → 4 人满员**自动开始**。

> 📱 手机、平板连同一 WiFi 也能玩，浏览器打开网址即可。

## 四、连不上？多半是防火墙

Windows 第一次运行会弹窗问"是否允许 Node.js 访问网络" → 点**允许**。
若没弹或误点了，手动放行 3000 端口，或临时关闭防火墙测试。

---

## 五、怎么玩（MVP）

1. 4 人加入同一房间 → 自动开始；
2. 轮到你时（名字高亮 + 按钮亮起）点 **掷骰子** → 再点 **前进**；
3. 棋子沿环形跑道前进，**先跑完 2 圈者获胜**；
4. 不是你的回合，按钮点不了（**服务器也会拒绝**，改代码作弊也没用）。

---

## 六、本机快速验证（不用开 4 个窗口）

**方式 A：开 2~4 个浏览器标签页**，都访问 `http://localhost:3000`，各填一个名字、同一房间号即可。

**方式 B：跑自动化脚本**（先 `npm start` 另开一个窗口）：
```bash
npm run test:clients
```
它会模拟 4 个客户端，验证"非当前回合的玩家被服务器拦截"。

---

## 七、下一步：把飞行棋规则搬进来

现在 `game.js` 里是个**跑道前进 demo**。要变成真正的飞行棋：

1. 把原 HTML 里的规则代码（棋盘数据、移动引擎、落点结算、技能……）**抽象成纯逻辑**搬进 `game.js`；
2. 每个"玩家动作"（掷骰、选方向、用技能）在服务器端**加一个校验 + 执行函数**；
3. 客户端把原来的"本地改状态"改成"`socket.emit(...)` 发指令"；
4. `publicState()` 里返回客户端渲染所需的全部信息。

> 关键原则：**服务器算，客户端画。** 客户端永远不自己改游戏状态。

## 八、常见问题

| 问题 | 原因 / 解决 |
|---|---|
| 别人打不开网址 | ① 不在同一 WiFi ② IP 填错 ③ 防火墙拦截 |
| 一直"等待玩家加入" | 4 人没满；房间号不一致 |
| 刷新页面后掉线 | 骨架未做断线重连（后续可加） |
| 部署到公网 | 需租一台能跑 Node 的服务器；静态托管（GitHub Pages）**跑不了** WebSocket |
