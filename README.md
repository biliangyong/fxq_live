# 鬼抓人 · 飞行棋 1v3

一个**纯前端、单文件**的非对称对抗小游戏：**1 只鬼 vs 3 名人类**，同屏轮流操作。

没有服务器、没有依赖、没有构建步骤——打开网页就能玩。

---

## 快速开始

**方式一：直接打开**

双击 `flying-chess-1v3.html`，用浏览器打开即可。

**方式二：起本地服务（推荐，确保棋盘底图正常加载）**

```bash
# 在项目根目录执行
python -m http.server 8000
```

然后浏览器访问：<http://localhost:8000/flying-chess-1v3.html>

## 玩法规则

### 阵营与目标

| 阵营 | 数量 | 目标 |
|---|---|---|
| 👻 鬼 | 1 名 | **淘汰全部 3 名人类** 即获胜 |
| ✈ 人类 | 3 名 | **破译四道密码 → 打开撤离门 → 撤离 2 人** 即获胜<br>（若仅剩最后 1 名人类，其撤离同样获胜） |

### 人类怎么赢

1. 人类进入四条**彩色专属道**，道深处各有一格金色 **「密」格**；
2. 在专属道中移动时，若骰点超过密码点会**反弹回退**；
3. 走到「密」格即**破译**该通道密码（同一通道不重复计数）；
4. **四条通道全部破译**后，鬼出生点的 **☠ 格**变为**撤离门**；
5. 让 **2 名人类**从撤离门撤出，人类阵营获胜。

### 鬼怎么赢

1. 鬼每次只能**捆绑 1 人**，须在 **3 个鬼回合内**把被捆绑者送到其**起始点（⌂ 格）**，超时则对方**挣脱并获得免疫**；
2. 被放到起始点的人进入 **2 个鬼回合倒计时**，期间**若无其他人类踩到该格解救，则淘汰**；
3. **淘汰全部 3 名人类**，鬼获胜。

### 其他机制

- **棋盘**：52 格环形跑道 + 四条彩色专属道；
- **同色格跳跃**：落在与自身同色格时，可继续选择跳跃；
- **眩晕**：人类踩到鬼所在格，令鬼**眩晕 1 回合**；若鬼正捆绑着人，会同时把被捆绑者救出；
- **阴阳 +1**：阵营技，改变骰点。

## 角色系统

开局选择角色，每个角色拥有多个主动 / 被动技能。

### 👻 鬼阵营

| 角色 | 特点 |
|---|---|
| **厂长** | 布置最多 2 个**布娃娃**并可与它们交换位置；可攻击相邻人类（使其接下来 2 个自身回合少走 1 格，不叠加） |
| **鹿头** | **钩爪**：沿指定方向抓回 3 格内的人类并捆绑（冷却 3 回合）；站在专属道入口时可抓入道内的目标 |

### ✈ 人类阵营

| 角色 | 特点 |
|---|---|
| **军人** | **晕眩弹**：无视距离与免疫，令鬼眩晕 1 回合（一局一次）；免疫鬼的减速 |
| **盲女** | **心灵预警**：与鬼距离 ≤ 6 格时可向远离鬼的方向移动 1 格（每回合一次）；**解密专家**：可在密码点前一格完成破译 |
| **光谱** | 连续两个自身回合开始时处于鬼的 6 格范围内，令鬼眩晕 1 回合 |

## 界面操作

- **掷骰子** → 选择移动方向 → 触发落点结算；
- 面板显示**回合提示、破译进度、玩家状态**；
- 支持**规则弹窗、音效开关、重新开始**；
- 角色选择会记住你的选择（`localStorage`）。

## 技术说明

- **纯原生实现**：HTML + CSS + JavaScript，**零外部依赖**；
- **棋盘绘制**：使用 **SVG** 动态创建节点（非 Canvas）；
- **音效**：**Web Audio API** 实时合成，不依赖音频文件；
- **本地存储**：`localStorage` 持久化角色选择；
- 全部逻辑集中在单个 `.html` 文件内，按注释分块：基础工具 / 音效 / 棋盘 / 棋子 / 骰子 / 移动引擎 / 落点结算 / 回合引擎 / 技能 / UI。
